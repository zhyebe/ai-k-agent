# Control Console Override

- This is an operational desktop console, not a marketing page. Keep the first viewport focused on task state, risk, workflow progress, and the next safe action.
- Use one prominent action per task state: `开始` in `READY`/`MANUAL_CONTROL`, `停止` while automatic control is active, and `人工处理` when a rule blocks execution.
- Preserve the deep charcoal canvas and low-saturation surfaces. Use green only for permitted/positive actions, amber for review, red for stop/error, and blue for neutral data provenance.
- Show every automation stage as text plus icon plus state color. Never rely on color alone.
- Keep panels dense but breathable: 8px radius, 16px internal spacing, tabular numerals, visible keyboard focus, and no decorative gradients.
