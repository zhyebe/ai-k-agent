# Axiom Agent v0.3.126

- 普通入场必须由 AI 明确决定 BUY/SELL；程序不从概率、指标或盘口分析字段推导普通开仓，自动救单除外。
- 离场由程序独立监控“持仓汇总”，直接点击对应商品、方向的“转让”，一次提交整行数量。多单 bid−订立均价 ≥ 0.5 点、空单订立均价−ask ≥ 0.5 点立即退出，包含 0.5、1，跳价超过 1 也立即执行。
- 亏损不足 3 点继续观察，达到 3 点保留原仓并执行原有两笔反向救单。救单后，同商品多空汇总“实时货值变化”合计金额 ≥ -1，立即退出该商品全部方向；触发后持续完成剩余方向，不再等待费用字段、单腿盈利或净利 ≥ 0。
- 救单满 10 分钟仍未恢复，独立请求 AI 预测未来 5 分钟内可达的离场价；到价由程序退出该商品多空汇总。预测从行情采集时刻起最多有效 5 分钟，过期重算，持仓或均价、数量变化即失效；合计金额 ≥ -1 始终优先立即退出。慢模型不阻塞离场监控。
- 汇总转让前核对商品、方向、真实均价、数量、冻结量及最新可成交报价，并更新弹窗旧价格。未核实结果持续审计，不重复提交。恢复退出先撤同商品未成交订立余量，退出锁定和有效预测在重启后继续核实，停止任务丢弃迟到结果。
- 共享交易 Skill、模型上下文和策略文档统一新规则。仅精确匹配已审核旧版正文的 Skill 自动升级，保留用户编辑。

桌面与服务端需配套升级至 v0.3.126；旧客户端明确提示升级。保留原有入场数量、120 秒撤余量、收盘清仓及停止控制。

验证：842 项测试通过，TypeScript 类型检查、Vite 生产构建及 Git 差异检查通过。测试使用隔离行情、模型与浏览器页面，未提交真实交易。
