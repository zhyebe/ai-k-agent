# Axiom Agent v0.3.131

- 入场所选方向盈利概率门槛改为≥40%，包含40%；40%～45%及以上均允许AI考虑下单。
- AI结合当前可成交价、预测路径、盘口、价差、滑点和已知费用，判断当前价或明确限价是否有合适盈利空间，再决定BUY、SELL或HOLD。概率达标不强制下单；价格不合适时可观望并说明依据。程序不选方向、不把HOLD变成交易。
- 删除概率达标强制下单、强制模型纠正动作，以及将达标HOLD判为分析失败的逻辑。模型JSON格式修复继续保留。
- 统一程序门槛、四种模型协议提示词、策略上下文、页面说明与交易Skill。精确匹配已审核v0.3.130原文后升级到v0.3.131，保留用户编辑。
- 盈利点差≥1立即持仓汇总整行离场；亏损点差≤-2由独立AI判断EXIT或HOLD。账户和当前委托核实清零后才能开始下一轮。

客户端需升级至v0.3.131，API与后台同步发布。验证使用隔离行情、页面和模型，未提交真实交易。

验证：622项全量测试通过，覆盖40%边界、40%～45%与更高概率、四种模型协议、AI选择市价或明确限价、达标HOLD不强制重试、不由程序选择高概率方向、持仓和当前委托对账及汇总离场。页面回归、TypeScript类型检查和Vite生产构建通过。
