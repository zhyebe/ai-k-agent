# AI价格计划与汇总离场

当前流程：核实空仓及委托清零，读取真实行情，AI同时预测入场与未来盈利离场价格；验证计划、费用、可成交价及全部数量深度后入场；持仓期间自动执行AI目标、利润保护、普通/硬止损与最长持仓期限。手动入场与自动入场均自动管理持仓。

## 入场要求

所选方向概率至少40%，不强制交易。多单使用已确认支撑低点的反弹区间，空单使用已确认阻力高点的受阻区间。AI必须提供`entry_price`及完整`trade_plan`，LIMIT另提供`target_price`。

计划字段、单位和边界定义见`server/trading-policy.mjs`的`TRADING_PLAN_SCHEMA`。无计划、不完整、过期、锚点不对应真实已确认K、买卖方向不符、实际价格越界，均HOLD。程序不补造默认目标或止损。

任务编辑中按商品代码填写`tradingCosts`，例如`{"DGKZ":0.2,"DGJJ":0.3}`，单位为每单位往返费用折合价格点。数值仅为格式示例，不是平台实际费率。留空为未知，实际免费才明确填0；费用未知禁止该商品新开仓。目标和利润保护必须在实际入场价扣费后保留正空间。

数据源若明确提供`roundTripCostPoints`，或提供现有`exitNetPnl`计价口径下整行往返`roundTripFee`/`totalFees`，同样纳入成本。整行费用按数量折成每单位点数，已知来源取较高成本核验，不用较低配置掩盖已知费用。外部金额若有合约乘数，须先按实际合约口径折算，不能直接把金额冒充价格点。

MARKET使用买入ask、卖出bid和完整数量的最差可成交价格。目标盈利只看买一/卖一价格不足以证明整行盈利。模型返回后、提交前、浏览器确认前重核账户、方向、价格、区间、深度和数量。

## 持仓计划

保留`entryForecast`，独立请求AI为每个商品方向生成`summaryTradingPlans`，包括：

- 目标、普通止损、硬止损。
- 普通止损确认秒数，由AI指定，0～300秒；连续真实报价突破才确认，恢复或观测中断结束该次观察，新的闪K不会重置。
- 计划复核有效期与最长持仓期限；复核到期继续执行已有保护，不撤销风险边界。原入场委托晚成交时，仍按原计划恢复风险保护和原始持仓期限，不因入场有效期已过而丢失止损；过期计划不能授权新开仓。
- 利润保护激活价、保护底线与允许回撤，记录最好可成交价，启动后保护边界只收紧。

AI目标、利润回撤保护、硬止损或最长持仓期限触发后，程序立即执行；不等第二次模型回答。普通止损依计划确认。AI可主动EXIT，但必须返回明确可接受离场价格及完整后续风险计划。新计划不能后移目标、放宽止损或延长持仓期限。

已有持仓费用未知时继续管理风险，界面显示净收益未核实，不把毛点差声称为已实现净利润。没有有效AI计划时请求失败会明确显示并重试，不伪造离场点、不增加新仓；因此接管旧仓前应确保AI服务正常。这仍依赖应用、浏览器、行情和交易通道持续在线，不是交易所原生托管止损。

## 执行与恢复

仅通过持仓汇总对应商品方向整行转让。最终确认前重核均价、数量、冻结量、报价、全部数量深度、AI授权和实际弹窗价格。弹窗刷新后的实际提交限价单独保存，不用旧建议价归因。

已提交或结果未知先对账。当前委托满120秒仅撤剩余未成交数量，保留已成交部分。没有明确委托ID时，使用基线之后唯一匹配商品、方向、订立/转让及数量的当前委托归因；多候选保留不确定性。

调用中断或委托消失不能直接声称成交。超过120秒后，至少两次相隔2～10秒的新鲜完整账户快照确认无相关委托、冻结解除、同向均价未变且剩余数量一致，才解除旧动作占用，并按有效计划重新判断剩余持仓。账户未核实、相关订单仍存在或冻结未解除时不重发。显示`RECONCILING`，避免误报普通监控。

确认持仓变化后记录`exitOutcomes`，限价与实际成交价分开，未知成交价保持null。离场后3/5分钟将待复盘商品加入报价轮询，已有持仓优先，每轮最多增加一个复盘商品，不额外串行采集多个盘口。只记录到期后10秒时窗内真实可成交报价及“若继续持有”的毛点差；手动表单等待、通道不可用或未采到的时窗记MISSING，不补造。这些观测回传AI用于判断过早止损和利润回吐，不能保证避免所有事后反弹。

## 兼容与验证

v1桌面应用与随包本机引擎一起更新，要求能力`browser-ai-trading-plan-v2`；旧固定+1/-2客户端不能执行新计划，无需单独部署外部服务器。仅对内容哈希和版本完全匹配的已审核内置Skill执行升级：单机内置版本为`v1.0.2`，历史数据库内置版本为`v0.3.134`。用户自行修改的内容保留，已删除的Skill不会恢复。

验证使用隔离模型、行情和本地浏览器页面，不运行真实交易。代码正确性测试不等于预测准确率或实盘盈利回测；仍需基于真实历史数据验证预测质量、费用、成交及风险。
