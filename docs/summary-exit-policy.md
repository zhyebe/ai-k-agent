# 短线预测与全部持仓离场

当前流程：核实空仓及委托清零后，AI按短线相对低位买涨、相对高位买跌，预测未来入场点、盈利离场K与失效条件。持仓期间用户优先离场规则独立执行，AI核心风险边界持续有效。手动入场与自动入场均自动管理持仓。

## 入场要求

AI看短线趋势和当前相对高低位，有机会即明确BUY/SELL，程序执行，不等待绝对最高最低或固定形态。方向概率仅作参考，不设40%或其他门槛，缺失概率不否决入场；HOLD仍由AI决定，程序不猜方向。

计划字段、单位和边界定义见`server/trading-policy.mjs`的`TRADING_PLAN_SCHEMA`。`trade_plan`、固定setup、精确K线锚点、参考区间和计划完整性不再作为入场门槛。不完整风险计划提示`AI_ENTRY_RISK_PLAN_PENDING`，持仓后一出现即独立请求完整目标与止损计划，不补造默认价格。有效AI持仓计划仍须通过方向、目标、止损和期限核验才启用。

删除手续费配置和费用、预计净利润入场门槛。`profit_protection`为附加保护，缺失或不合理时标记未启用，核心目标、止损及期限继续执行，不补造保护价格。保本保护和大于初始利润的回撤距离可按有效AI计划使用。

MARKET使用买入ask、卖出bid和完整数量的最差可成交价格。模型返回后、提交前、浏览器确认前重核真实账户、品种、数量和新鲜盘口，刷新市价单实际提交价，正常跳价不因旧参考区间取消重算；LIMIT保留AI明确`target_price`或`entry_price`。停止开关、授权时效和防重复提交继续生效，提交结果未知先对账。目标盈利只看买一/卖一价格不足以证明整行盈利。

## 用户优先离场

独立监控全部N笔持仓。多单点差为整行最差可成交bid减订立均价，空单为均价减整行最差可成交ask；合计乘各行真实数量，不遗漏负值，不将未知报价当0。该合计为可成交价差，不是已实现净收益。

1. 合计大于0，立即锁定全部持仓离场，不等待AI或未来K。先退部分后剩余合计变负，也继续完成批次，直到持仓及相关委托对账完成。
2. 同持多空且合计未盈利，先退亏损侧，保留盈利侧；两侧均亏则退出两侧。保留侧在清理期间转亏也加入亏损侧退出。
3. 亏损侧持仓及相关委托确认清除后，保留盈利侧最多观察60秒。每个商品方向分别监控，任一保留侧利润回落或转非正提前离场；持续增加到时也立即提交。AI更新、重启和新跳价不延长期限。
4. 保留盈利侧观察期间，普通合计正值规则不立即覆盖限定观察；硬止损、确认普通止损及最长持仓期限持续有效。

无AI计划或模型离线时，用户规则也独立工作。离场批次绑定均价、方向和数量，均价变化或数量增加使旧批次失效，不能沿用旧授权清理新增仓位。

全部持仓品种轮换采集，只合并同任务代际、同会话、同持仓身份且5秒内的真实盘口，单独记录账户时间。未覆盖所有持仓、过期、冻结或持仓表不一致时不认定合计盈利，已有独立AI风险保护继续执行。60秒为最长观察和触发提交期限，实际成交仍需通道、账户和深度核实。

## AI持仓计划

保留`entryForecast`，独立请求AI为每个商品方向生成`summaryTradingPlans`，包括：

- 目标、普通止损、硬止损。
- 普通止损确认秒数，由AI指定，0～300秒；连续真实报价突破才确认，恢复或观测中断结束该次观察，新的闪K不会重置。
- 计划复核有效期与最长持仓期限；复核到期继续执行已有保护，不撤销风险边界。原入场委托晚成交时，仍按原计划恢复风险保护和原始持仓期限，不因入场有效期已过而丢失止损；过期计划不能授权新开仓。
- 可选利润保护激活价、保护底线与允许回撤，记录最好可成交价，启动后保护边界只收紧。

用户优先规则之外，AI目标、有效利润保护、硬止损或最长持仓期限触发后直接执行，不等第二次模型回答；保留盈利侧的限定观察仍受必要风险边界约束。逐根真实定K对比原始预测、趋势与失效位，闪K是未确认观察，不能当已确认反转或单独授权立即止损。普通止损依计划连续确认。AI可主动EXIT，须返回可接受价格和核心计划。新计划不能后移目标、放宽止损或延长持仓期限。

没有有效AI计划时明确显示失败并重试，用户离场规则仍独立生效，不伪造风险价位。有效AI风险保护启用前存在计划等待窗口。监控依赖应用、浏览器、行情和交易通道在线。

## 执行与恢复

仅通过持仓汇总对应商品方向整行转让。最终确认前重核均价、数量、冻结量、报价、全部数量深度、有效AI或用户批次授权和实际弹窗价格。实际提交限价单独保存，不用旧建议价归因；单笔失败继续其他持仓。

已提交或结果未知先对账。当前委托满120秒仅撤剩余未成交数量，保留已成交部分。没有明确委托ID时，使用基线之后唯一匹配商品、方向、订立/转让及数量的当前委托归因；多候选保留不确定性。

调用中断或委托消失不能直接声称成交。超过120秒后，至少两次相隔2～10秒的新鲜完整账户快照确认无相关委托、冻结解除、同向均价未变且剩余数量一致，才解除旧动作占用，并按有效计划重新判断剩余持仓。账户未核实、相关订单仍存在或冻结未解除时不重发。显示`RECONCILING`，避免误报普通监控。

保存`summaryExitBatch`的批次、阶段、逐侧利润样本及最晚期限，恢复不延后观察时间。确认持仓变化后记录`exitOutcomes`，限价与实际成交价分开，未知成交价保持null。离场后3/5分钟将待复盘商品加入报价轮询，已有持仓优先，每轮最多增加一个复盘商品。只记录到期后10秒内真实可成交报价及“若继续持有”的毛点差，未采到记MISSING，不补造。这些观测用于AI复核过早止损，不能保证避免所有事后反弹。

## 兼容与验证

v1桌面应用与随包本机引擎一起更新，无需单独部署外部服务器。仅对内容哈希和版本完全匹配的已审核内置Skill精确升级，包括已发`v1.0.2`/`v0.3.134`及`v1.0.3`/`v0.3.135`的原文；目标单机版本`v1.0.4`，历史数据库版本`v0.3.136`。用户自行修改或待审核的内容保留，已删除的Skill不会恢复。

验证使用隔离模型、行情和本地浏览器页面，不运行真实交易。代码正确性测试不等于预测准确率或实盘盈利回测；仍需基于真实历史数据验证预测质量、费用、成交及风险。
