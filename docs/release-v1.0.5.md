# v1.0.5 — 修复交易确认卡住与离场执行失败

本版本修复入场确认被弹窗阻塞、确认失败后残留弹窗，以及行情正常变化导致离场失败的问题，并补充 Windows 发布检查。

## 交易执行修复

- 入场最终确认期间，使用经过精确定位的只读账户页签与分页控件重新采集账户数据，避免确认弹窗遮挡鼠标点击而卡住。继续完整核对持仓明细、持仓汇总和当前委托，不跳过空仓检查。
- 最终确认正确读取通过 `label for` 关联的价格、数量字段，避免填写成功后误报表单已变化。
- 确认按钮不可用或确认超时时明确返回失败，并关闭本次动作的残留弹窗，避免误记为等待成交、阻塞后续执行。
- 弹窗清理按本次动作与实际 DOM 节点定位；弹窗已经自动关闭时不再等待失效节点，避免额外卡顿和清理误报。
- 离场价格在填写后变化、但最新报价仍满足 AI 离场授权时，在同一弹窗内最多重新定价两次。每次仍检查持仓、冻结数量、深度、AI 价格边界与授权有效期；超出次数或条件失效时取消本次动作并重新观察。
- 可能已经提交的动作优先对账，不因后续价格检查失败而当作未下单重新提交。尚未提交的入场条件失效时，取消旧建议并重新获取行情。
- 保留浏览器读取失败和登录过期的实际错误，避免被统一包装为盘口或账户变化。

## Windows 与升级

- Windows 发布流程增加持仓汇总离场回归；打包后的 Electron 冒烟使用真实遮挡页面的确认弹窗，覆盖多空入场、离场、窗口最小化、隐藏和 DOM 重绘。
- 发布 macOS universal、Windows x64 安装版与便携版，并更新应用内自动更新元数据。
- 更新保留本机配置、任务与加密凭据。关闭应用前确认已有实盘持仓；重新打开后，核对目标页面、持仓与交易计划再恢复任务。

自动化检查使用隔离交易页面，不提交真实订单。具体验证结果以本次发布流水线为准。
