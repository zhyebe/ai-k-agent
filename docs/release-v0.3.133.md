# Axiom Agent v0.3.133

- 闪K定义统一为突然上拉或下拉但尚未定K；识别不再要求先回弹，也不再依赖有没有影线。保留闪K事件给AI，未定K从确认历史指标、趋势及普通亏损判断中排除。
- 盈利点差≥1时，包含闪K盈利和直接跳过1点，仍立即按商品、方向在持仓汇总整行转让，不等待AI。
- 亏损点差≤-2时，先连续观察30秒排查闪K。使用新鲜可成交报价，相邻采样不超过10秒；恢复阈值内、采样中断、持仓变化或新闪K事件出现时重置窗口。同一已保留事件不会反复重置。
- 观察确认持续亏损后，独立请求AI决定EXIT或HOLD；请求同时提供连续报价、保留的闪K事件、未确认盘中证据和确认历史。旧观察对应的迟到AI结论不能执行。
- 多商品轮询保留各自观察和在途判断；持仓清零或停止任务清理观察。页面显示亏损观察进度，运行状态同步持久化。
- 同步模型提示词、策略说明和交易Skill；只升级精确匹配的已审核旧版本，保留用户自行编辑的内容。

客户端需升级至v0.3.133，API与后台同步发布。测试使用隔离行情、页面和模型，不提交真实交易。

验证：631项全量测试通过；最终闪K、亏损观察和汇总离场聚焦回归通过；TypeScript类型检查、Vite生产构建及2项入场页面回归通过。完整页面套件32项通过，7项失败已在v0.3.132原始代码复现（旧10K文案、已移除的收盘设置/救单UI、既有首屏布局断言），不归入本次修复结果。
