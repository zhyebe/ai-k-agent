# Axiom Agent v0.3.130

- 修复“空单45%，却解释为不足45%并HOLD”的入场矛盾。空仓、持仓汇总、当前委托均已核实清零且两侧概率完整时，任一方向盈利概率≥45%（包含45%），由AI在达标方向中明确选择BUY或SELL；两侧均低于45%才因概率不足观望。
- 统一模型提示词、行情上下文、共享交易Skill与页面规则。震荡、偏弱、未突破、点差和指标分歧计入概率，不在概率达标后增设HOLD门槛。
- 模型动作与概率矛盾时，将原结论、精确概率及同一行情交回同一模型纠正一次。保留原始概率，程序不选择方向。纠正失败明确报告分析失败并重新分析；格式修复与动作纠正共用一次重试预算。
- 页面和日志向下保留两位百分数，44.99%不会显示成45%，执行比较原始数值。服务端识别旧客户端的矛盾HOLD，避免当作成功分析。
- 精确匹配已审核v0.3.128交易Skill原文后升级为v0.3.130；用户编辑保留。盈利≥1点立即汇总离场、亏损≤-2点由AI判断的规则保持一致。

客户端需升级至v0.3.130，API与后台同步发布。测试使用隔离行情、页面和模型，未提交真实交易。

验证：600项全量测试通过，包括四种模型协议的45%边界纠正、两侧达标仍由AI选择、未达标观望、纠正失败、单次重试预算、账户未核实或有仓委托不入场，以及AI纠正为空单后只提交一次的完整链路。页面回归、TypeScript类型检查与Vite生产构建通过。
