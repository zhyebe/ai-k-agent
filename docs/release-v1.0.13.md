# Axiom Agent v1.0.13

修正闪K识别与正常行情长期不入场的问题。AI预测入场、盈利目标和失效价格，算法按本盘上下影线形态控制进出场；保留原始目标、合理止损及全部持仓监控。

- 上下都没有影线才判闪K，即最高价等于实体顶部且最低价等于实体底部。只有一侧没有影线不判闪K；不再用跳价、涨跌幅、成交量变化或PROVISIONAL历史标签替代形态判断。
- 正常带影线K不再因历史确认计时额外等待第50秒、5秒稳定或下一根K。入场、持仓汇总离场及浏览器最终确认使用同一规则。
- 闪K期间保留已授权的AI方向；真实观察到当前K出现任一影线或后续正常K后继续入场。离场按最新可成交报价重新核对目标、止损及多空规则，恢复则不离场。
- 双无影线不因时间经过成为已确认历史。已等待动作不能由旧缓存、旧K、缺失图表或事件超时解除；历史确认与当前可执行价格分开记录。
- 价格结构不变时，成交量正常增长不再反复清空历史价格稳定观察。
- 等待入场期间账户暂未核实或页面采集失败，即使界面临时显示HOLD，恢复后仍使用已保存的原AI买卖动作、目标和止损，避免动作被清空或卡住。
- 原盈利目标、普通及硬止损、多空处理、停止开关、防重复及提交结果对账继续生效。提交不等于成交。

随包知识升级至v1.0.13，历史数据库知识升级至v0.3.140；只按已发布原文的版本和哈希精确升级，保留用户编辑与删除状态。验证使用隔离行情、模型和本地交易页面，不操作实盘。
