# Axiom Agent v1.0.16

- 单机任务统一使用本机算法。启动实盘后自动进出场，程序处理交易网页普通确认，无需逐单授权或选择决策方式。
- 上涨等相对低位做多，下跌等相对高位做空。成交后逐商品、逐方向使用新定 K 更新离场预测。预计亏损时最多等待两根 K 寻找回弹减亏，新定 K 明显否定回弹时提前止损。
- 闪 K 等正常定价后按最新盘口重判。提交失败会继续监控，重启前结果未知的订单先核对委托和持仓。新任务默认影子记录，已有任务保留运行模式，重启后暂停。
- 三段分钟 K 回放的毛点差分别为 +77、+191、+30 点，原固定目标算法分别为 +85、+158、−38 点。回放缺少买卖盘口、滑点和成交成本，实盘净收益待验证。
