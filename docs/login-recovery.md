# 网站登录过期恢复（v0.3.88）

主分析启动前检查登录。采集期间与每 2 秒的持仓观察发现 REAUTH_REQUIRED 时，立即使用托管凭据自动登录，再读新的持仓/委托数据，继续原任务。两个监控并发失效共享一次登录；读取跨越恢复时重新读取即可，避免重复登录。未提交或结果未知的交易不会因登录恢复自动重放。

可见登录过期提示优先于交易页 URL、旧行情和缓存 sessionStorage。过期页没有登录表单时导航到连接器已审核的同源登录地址，自动填表提交，返回目标交易页后再次核实登录。正常监控不刷新页面。隐藏的旧提示、交易密码弹窗不能被当作登录失效。

登录失败保留监控意图并自动重试，不把旧数据当作新行情或空仓。单轮只重试一次采集，避免无限循环。凭据不存在或站点拒绝登录时如实记录失败，不能声称监控已恢复。恢复成功清除旧的重试延迟，立即唤醒主分析。登录期间返回的旧会话分析不执行，下轮立即基于新数据分析；已有效的逐仓条件仍结合新报价核实执行。

回归覆盖采集中途失效、快速离场监控恢复、并发登录、失败后继续监控、恢复后再失效、旧分析作废、真实浏览器过期覆盖旧行情及隐藏提示不误判。测试使用隔离网页和模拟订单，不触发生产交易。
