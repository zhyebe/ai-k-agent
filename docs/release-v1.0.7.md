# v1.0.7 — AI 入场决定直接执行

修复 AI 已决定买卖，却被剩余策略条件改成观望，以及正常跳价导致市价入场反复取消的问题。

- 取消方向盈利概率 40% 门槛；低概率、缺少概率均不再否决明确 BUY/SELL，程序不替 AI 选方向或把 HOLD 强制改成交易。
- 取消固定支撑反弹/阻力受阻形态、精确历史 K 线锚点、参考价格区间和风险计划格式的入场否决。目标与止损字段仍保留为原始预测，缺失或无效明确提示，持仓后一出现即独立请求完整风险计划，不伪造默认风险价位。
- 市价入场在提交前及网页最终确认前刷新真实买入 ask / 卖出 bid 的完整数量价格，正常跳价继续执行并记录实际提交价。限价单保留 AI 明确价格。
- 更新模型指令、界面与内置知识，短线趋势和相对位置支持交易即决定，不等绝对极值、固定形态或指标共振。旧内置知识按版本与内容哈希精确升级，保留用户编辑。
- 保留真实账户、品种、数量、新鲜盘口、防重复、停止开关和授权时效核验；未清零轮次及结果未知的提交先对账。保留全部持仓盈利全平、多空亏损侧退出与盈利侧最多 60 秒兑现。

缺少有效风险计划的入场可能产生等待 AI 持仓计划的窗口，用户优先离场规则继续独立执行。模型预测不保证正确，提交与实际成交仍以真实账户对账为准。

提供 macOS universal、Windows x64 安装版和便携版，随包更新本机引擎与自动更新元数据。验证使用隔离行情、模型和本地页面，不提交真实订单。
