# v0.3.135

- 普通亏损持仓先连续观察 60 秒。60～120 秒内，连续报价确认亏损扩大时允许 AI 判断止损；满 120 秒仍连续扩大，由程序执行止损。亏损持平、收窄或仅有一次跳价不会因到时被强平。
- 亏损观察期间恢复到该持仓已知费用后的净盈亏 ≥0，交给 AI 优先判断保本或小利离场，允许低于普通 1 点盈利门槛。净盈亏为 0 表示保本，费用未知不当作零费用。
- 未确认跳价先进入闪 K 观察；闪动结束并取得连续稳定的报价后重新判断普通止损。新闪动会使旧止损证据失效，等待新的连续走势。
- 普通盈利仍由 AI 在 ≥1 点后选择离场点，≥4 点由程序强制离场；清理旧提示词中“1 点立即强制退出”的冲突内容。
- 救单组合规则保持：原单加两笔反向救单，按本组合净盈亏 ≥0 整组离场，全部离场并核实委托前禁止普通新开仓。收盘清仓继续优先执行。
- 点击转让与确认弹窗时再次核对持仓和价格。过期的原生确认弹窗取消后重新观察，避免沿用旧止损条件。

连续观察只累计新鲜、相同持仓的报价；报价中断、成本或数量改变、重新启动观察时重新计时。升级会同步精确匹配的内置交易经验，保留用户编辑过的经验。
