# Axiom Agent v0.3.128

- 普通入场只执行 AI 明确选择的 BUY/SELL，所选方向盈利概率至少 45%。持仓、持仓汇总、当前委托或提交结果尚未核实清零时，不开启下一轮。
- 盈利点差达到或超过 1 点，程序立即在持仓汇总按商品和方向整行转让，不等待 AI 或下一根 K。多单点差为 bid−订立均价，空单为订立均价−ask；不乘数量，不按盈亏金额判断。
- 亏损点差达到或低于 -2 点，独立请求 AI 决定 EXIT/HOLD。只有 AI 明确 EXIT 才离场；慢请求或旧 HOLD 不阻塞后续盈利离场。
- 点击及确认前重新核对真实汇总均价、数量、冻结量与当前可成交报价。提交结果未知时持续核实，禁止重复转让；实际持仓、汇总及当前委托均清零后，才开始下一轮。
- 删除旧版 0.5 点离场、3 点反向救单、恢复金额 -1 退出、10 分钟救单和 5 分钟目标、逐仓离场、收盘清仓及额外同 K 入场锁。修复现场已清零但旧待核实动作持续阻塞入场的问题，不伪造历史成交结果。
- 统一页面、模型上下文、共享交易 Skill 和策略文档。仅精确匹配已审核旧版正文的 Skill 自动升级，保留用户编辑。

- 打包后的浏览器自检按新流程核实空仓，再验证多空持仓汇总整行离场；保留窗口最小化、隐藏、控件重绘、模型不可用、登录与撤单验证，确保没有逐仓转让。

桌面与服务端需配套升级至 v0.3.128；旧客户端需升级后使用新策略。当前委托满 120 秒仍只撤未成交余量，停止任务丢弃迟到的 AI 结果。

验证：572 项测试通过，TypeScript 类型检查、Vite 生产构建及 Git 差异检查通过。完整离场链路使用隔离交易页验证，未提交真实交易。
