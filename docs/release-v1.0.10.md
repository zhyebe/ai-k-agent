# Axiom Agent v1.0.10

修复 AI 已给出止损但持仓没有实际离场的计划绑定与提交断点，保留 v1.0.9 的原目标持仓和闪 K 入场判断。

- 进出场统一由算法检查真实定价。闪 K 或 PROVISIONAL 期间所有离场等待，包括止盈、普通及硬止损、利润保护、持仓期限和多空清理；AI 无法绕过。定 K 后按最新报价重判，恢复则不离场。
- 每个持仓方向保存闪 K 等待状态，重启、计时到期、缓存复读或图表缺失不能直接放行。闪 K 不累计普通止损确认时间、不抬高保护峰值，最终转让弹框中新闪 K 也会取消未提交确认并等待。
- 新鲜持仓汇总确认同商品、同方向增仓后立即启用原入场风险计划，不等待持仓明细加载；逐笔成交仍独立对账，不重复下单。
- 原计划中明确的目标、普通止损和硬止损不因理由或复核期限缺失被整体拒绝。缺少普通止损确认时间时请求 AI 补充，硬止损继续执行；不编造价格、等待秒数或最长持仓时间。
- 成交滑点越过原目标或硬止损时保留原 AI 价格，仍按当前真实风险触发离场，不因成交偏离参考价丢弃保护。
- 普通止损进入转让弹框后进一步穿过硬止损，继续执行离场，不因风险等级升级主动取消。
- 已连续确认的普通止损在原授权有效期内保持有效，慢弹框不再撤销；最终真实报价恢复则仍取消离场，过期授权不沿用。
- 界面显示实际启用的离场计划、缺少的确认时间或期限，以及计划安装错误，避免将入场预测误认为已执行止损。

离场仍受真实账户、可成交报价、深度及交易通道约束；提交成功不等于成交。回归使用隔离行情、模型和本地交易页面，不操作实盘。
