# v1.0.3 — AI 入场与离场计划修复

本版本包含 v1.0.1 之后的完整交易修复。v1.0.2 的打包冒烟拦截了仍使用旧协议的测试夹具，未发布安装包；本版本补齐测试中的商品、AI 入场及持仓计划，保留原有执行校验和发布门禁。

## 交易修复

- AI 同时返回支撑反弹或阻力受阻的入场区间，以及目标、普通止损、硬止损、确认时长、最长持仓和利润保护。计划缺失、过期或与真实行情不符时停止新开仓，不补造预测点位。
- 模型返回后、下单前和网页最终确认前复核商品、方向、价格区间与完整数量深度。新增按商品配置每单位往返费用折合价格点，避免忽略费用和深度导致虚假盈利空间。
- 达到 AI 目标、利润保护回撤、硬止损或最长持仓期限时执行离场，无需等待下一次模型回答。普通止损按计划连续确认，新的闪 K 不再反复重置；后续计划不能放宽止损、后移目标或延长持仓。
- 修复委托晚成交、部分成交和调用中断后的保护恢复及对账。实际提交限价与实际成交价分别记录；账户和委托未核实前不重复下单。
- 离场后采集 3/5 分钟真实报价供 AI 复盘，未采到明确记录缺失，不补造行情或把限价声称为成交价。
- 仅迁移版本、审核状态及内容哈希完全匹配的旧内置策略；保留用户编辑，不恢复已删除策略。单机内置策略版本为 v1.0.2，与桌面发布版本独立。

## 升级后配置

在任务编辑中按商品填写真实往返费用折合价格点，留空表示未知，确认免费才填 0。费用未知时禁止新开仓；已有持仓继续管理风险，净收益未核实会明确显示。

桌面应用与本机引擎一起更新，无需部署外部服务器。本机任务、AI 配置和加密凭据保留；重启后任务暂停，确认行情、持仓及配置后再启动。

执行 AI 计划和风险边界依赖应用、浏览器、行情及交易通道持续在线。预测可能出错，不能保证盈利或避免所有止损后的反弹。测试使用隔离模型与行情，不代表实盘盈利回测。
