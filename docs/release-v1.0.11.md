# Axiom Agent v1.0.11

AI负责预测入场、盈利目标与失效价格，确定性算法负责定K、止损监控和实际离场。修复v1.0.9之后发现的止损计划绑定与执行断点；v1.0.10发布已取消。

- 闪K或PROVISIONAL期间所有离场等待，包括目标、普通止损、硬止损、利润保护、最长持仓和多空处理；AI无法绕过。真实定K后按最新可成交报价重判，价格恢复则不离场。
- 真实报价持续越过普通止损时，连续风险观察跨分钟保留，不被每根新K清零。已达到AI指定确认时长且定K仍越界就执行；缓存不增加确认时间，报价恢复或采样中断重新观察。
- 闪K不抬高利润保护峰值。每个商品方向保存等待状态，重启、事件到期、缓存复读或图表缺失不能直接放行；最终弹框中新闪K会取消未提交确认，继续等待。
- 新鲜持仓汇总确认同商品、同方向增仓后立即启用原入场风险计划，不等待持仓明细加载；逐笔成交仍独立对账，不重复下单，不重置原入场时间。
- 原计划明确的目标与止损不因理由或期限缺失被整体拒绝。缺少普通止损确认时间则请求AI补齐，明确硬止损继续生效；不编造价格、确认秒数或持仓期限。成交滑点越过原目标或硬止损也保留原价格。
- 普通止损在弹框中升级为硬止损时继续离场；已完成确认的止损在原授权期限内不因弹框较慢被撤销。最终报价恢复则取消，过期授权不沿用。
- 界面区分入场预测与实际启用的离场计划，显示缺少的确认时间、期限、计划安装错误及定K等待状态。
- 保留原始AI目标持仓，例如16～19入场、目标21，预测未失效且风险边界未触发时持有至目标；不因刚浮盈或仅过一根K提前退出。闪K入场同样等待真实定价。

离场使用真实账户、可成交报价、整行数量与深度，并保留停止、防重复和结果对账；提交不等于成交。回归使用隔离行情、模型和本地交易页面，不操作实盘。
