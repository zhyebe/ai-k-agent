# Axiom Agent v0.3.132

- AI主动、大胆预测：有可用行情时明确最可能的偏涨、偏跌或震荡主场景，给出下一K及随后1～3根K价格路径、合适入场价与失效位，避免只复述历史或罗列所有可能。
- 普通指标分歧、尚未突破或未到完美极值，不再成为回避主判断的理由。用真实概率、证据和反证表达不确定性；估计价位与已观察行情区分，不人为抬高概率。
- 快速分析也明确要求next_k和next_3k预测路径与失效位，HOLD仍需说明具体价格依据和未来路径。
- 包含≥40%的入场规则，40%～45%及以上均可由AI评估当前价或明确限价的盈利空间。概率达标不强制下单，AI继续独立决定BUY、SELL或HOLD；程序不选择方向或把HOLD变成交易。
- 同步模型提示词、策略上下文与交易Skill；仅升级精确匹配的已审核旧Skill，保留用户编辑。盈利点差≥1立即汇总离场，亏损点差≤-2交给AI判断。

客户端需升级至v0.3.132，API与后台同步发布。验证使用隔离行情、页面和模型，未提交真实交易。

验证：622项全量测试通过，四种模型协议均验证主动预测指令、next_k/next_3k路径与失效位保留、40%门槛及达标HOLD不强制纠正；已审核Skill精确升级与用户编辑保护通过。2项页面回归、TypeScript类型检查和Vite生产构建通过。
