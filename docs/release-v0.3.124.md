# Axiom Agent v0.3.124

- 救单开始后硬性禁止普通新开仓，覆盖待提交、待成交、部分成交、结果未知及整体离场阶段。已生成的旧开仓建议也不能绕过限制。
- 启动观察时，同一品种同时存在多仓和空仓，直接识别为救单组并锁定新开仓；已有救单状态在重启、停止后重新观察时继续保留。
- 本轮开始时已有 n 笔原仓，逐笔满足原有亏损 3 点条件后，各允许一次同品种反向救单。同一原仓亏损继续扩大也不追加；救单腿不循环互救。
- 持续监控原有账户净利恢复和整体离场逻辑，只有全部持仓离场、当前委托核实为空且没有待核实的入场动作，才解除限制并进入下一轮。
- 其他原有策略保持：普通持仓的新 K 入场、普通单 1～4 点收益目标、3 点救单门槛、配置下单数量、120 秒撤余量、收盘清仓及用户停止逻辑。

验证：救单、交易引擎、模型协议、持仓退出、委托及持久化回归 675 项通过；TypeScript 类型检查和 Vite 生产构建通过。测试使用隔离行情、模型响应和交易夹具，没有提交真实交易。
