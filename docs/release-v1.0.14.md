# Axiom Agent v1.0.14

新增「本机算法」决策方式，可独立预测入场价区间、止盈目标、预计离场时间和止损价。

- 创建任务或停止后编辑任务，在「决策方式」选择「本机算法」。切换时默认进入影子模式，只记录信号。
- 用已结束的分钟 K 识别短线方向，在相对低位寻找做多机会，在相对高位寻找做空机会。用相似历史走势估算目标和持仓时间。
- 等正常定价后复核入场。成交后持续监控持仓，保留原目标和止损。闪 K 期间等待，恢复正常定价后按最新盘口重判离场。
- 支持分钟 K 初筛和历史盘口回放。537 独立时段总盈 425 点、总亏 267 点，毛差 +158 点。536 样本毛差 −38 点。实盘净收益仍需用历史买卖盘口和实际成交成本验证。
