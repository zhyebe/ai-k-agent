# Axiom Agent v1.0.8

修复“入场弹框出现又消失，但没有订单”的字段识别错误。

- 真实交易网页使用外层 `li` 包住整块订立表单，下单按钮本身也是 `input`。旧最终复核把该按钮误当成额外的价格和数量字段，随后主动点击取消。按用户要求删除整段入场二次复核，填表后直接点击下单、确认。
- AI 明确买入或卖出后，不再重新读取账户、核对深度或用时效和表单规则否决动作；取消分析后和提交前的重复账户采集。市价随可读的真实盘口更新，盘口暂缺时继续使用本次 AI 已确定的价格；不添加虚构价格。
- 确认前核对按钮实际文案，AI 选择的取消、关闭或返回按钮不能作为确认执行。
- 执行记录区分已确认与主动取消，保存实际按钮文案、具体失败原因及执行阶段。确认按钮不可用等执行错误直接显示原因。
- 浏览器与桌面打包夹具补上真实网页的外层表单结构，覆盖多空入场、手动确认、市价刷新及后台窗口恢复。

保留停止开关、防重复提交及持仓离场监控。平台明确拒单显示真实结果；提交结果未知则核实委托和持仓，不把弹框消失当作成交。未执行真实交易。

验证范围包括多空真实表单结构、AI 建议后不重复采集账户、缺少账户表格或盘口深度时仍提交、旧时效不再取消明确动作、确认与取消文案记录、未知提交防重复，以及可见、隐藏和最小化窗口中的入场与离场。Windows 和 macOS 安装包继续执行浏览器及单机启动检查。
