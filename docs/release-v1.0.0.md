# v1.0.0 — 单机开放版

- 移除桌面端账号登录、退出账号和服务器地址配置。启动直接进入工作台，首次使用引导配置 AI。
- 桌面自带本机运行引擎，无需部署服务器、数据库或管理后台；构建产物不再包含后台页面。
- 任务、AI Provider、经验和目标凭据持久保存到本机。API Key 和目标密码使用本机生成的密钥加密。
- 内置交易 Skill；保留现有行情采集、AI 分析和交易执行规则。
- 本机模型选择与浏览器会话范围使用稳定标识，不受每次启动端口变化影响。
- 重启恢复配置，交易任务保持暂停；退出时关闭浏览器和引擎并等待存储写入。
- 数据损坏、密钥缺失或写入失败明确报错，不转入演示或临时内存模式。
- 旧服务器地址、登录令牌和数据库配置不参与单机启动。旧服务端数据需自行导出所需内容，再在本机配置或导入；不自动迁移。

版本号统一为 `1.0.0`。更新检查直接访问 GitHub，可用性不影响工作台启动。在线 AI 和目标网站仍需网络。
