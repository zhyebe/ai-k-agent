## 填写规则

1. 一份文件只写一个可独立审核的知识单元。
2. 结论必须绑定适用条件、触发信号和失效条件。
3. 阈值、时间、对象尽量写具体数值和单位。
4. 不确定内容写入“已知局限”，不要伪装成确定规则。
5. 红线只写必须停止或转人工的条件，不把普通建议写成红线。
6. 专家填写后，在用户端完成审核发布；发布前内容不会进入自动决策。
