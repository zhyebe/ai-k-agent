# Axiom Agent v0.3.129

- 修复模型缺失置信度时被误显示为 0% 的问题。页面、输出流及工作流显示“置信度未提供”，模型明确返回 0 时仍显示 0%。
- 历史对话与持久化保留未知置信度，避免后续分析和重启将缺失数据误读为真实 0%。
- 入场请求明确要求返回所选动作（包括 HOLD）的置信度，并区分置信度与多空盈利概率。
- 普通入场仍由 AI 明确选择 BUY/SELL，所选方向盈利概率至少 45%；AI 主动 HOLD 保持观望，置信度不是入场门槛。盈利点差至少 1 点立即汇总离场，亏损点差至多 -2 点由 AI 判断 EXIT/HOLD。

本次修复包含桌面本机模型请求逻辑，客户端需升级至 v0.3.129；API 与后台同步发布。

验证：574 项测试通过；45% 多空入场及缺失置信度日志验证通过；HOLD、缺失置信度和真实 0% 的页面回归通过；TypeScript 类型检查、Vite 生产构建及 Git 差异检查通过。未提交真实交易。
