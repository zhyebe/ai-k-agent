# DGKZ / DGJJ 入场离场研究技能

## 目标与边界

目标是在可承受损失和可成交约束下改善净收益，给出有依据的入场、退出和失效条件。不能事前知道最高卖点、最低买点或最大利润。日涨跌预测与一笔交易的盈利分开评估：方向判断正确也可能先触发止损。

默认分析两个品种；已持仓时先评估退出，再评估新入场。没有AI控盘证据时，正常评估开仓，不能以猜测暂停开仓；满足预先登记的行情、成本和风险条件时，输出“条件满足，可开仓”的研究计划，由用户执行。条件未满足时可以等待；未取得行情时说明资料不足，不伪造当前价格。只有数据、规则、流动性、成本及样本外表现共同支持时，才把研究候选标为经验证建议；用户选用未验证方案时明确其状态，继续给出条件、成本及风险预算。

本技能用于研究、记录和回测，不承诺收益或胜率。调用技能、提供凭证或授权读取页面不代表授权交易；不得自行下单、改价、撤单、设置止盈止损或转账。不保存或输出账号、密码、Cookie、session token、银行卡、身份证或可识别账户信息。其他软件没有浏览器或行情连接能力时，技能不会自动获得实时数据；明确说明缺少连接，只分析用户已提供且有时间戳的数据，不虚构访问或行情。

## 数据纪律

1. 记录抓取时间（北京时间）、服务器/接口、代码、合约版本、数据截止时间。严格区分最新价、最后成交价、结算价、收盘价、均价、买一卖一。
2. 交易日按核实的会话边界映射。DGKZ 样本显示前夜成交与次日日线衔接；映射须以原始成交及实际交易日字段复核，不能直接套其他市场的夜盘规则。未收盘日线、周线、月线不能用于已完成周期信号。
3. 每根 K 线校验时间递增、OHLC 关系、数量非负、成交金额和成交量口径。发现重复、断档、未来时间、动态当日 K 线或跨时段拼接，标为无效或未完成。
4. 只使用预测发布时间前已知的数据。盘中更新另立版本，不能回写覆盖开盘前预测。
5. 最小输入：前一交易日结算价、最近已完成日线、5分钟或更细行情、成交量/金额、买卖一档和深度、订货/存货字段定义、有效费用、公告及可交易时间。缺一项关键数据就降低置信等级或输出“资料不足”。

## 日前与盘中流程

### 开盘前

先检查开市、品种有效性、规则公告、数据完整性和是否临近最后交易/交收日期。计算最近5/20根已完成日线收盘均值、14日真实波幅、前高前低、结算价变化、成交量变化和存货/订货变化。真实波幅TR=max(高-低, |高-前收|, |低-前收|)；初始报告采用最近14根TR的简单平均，后续若改用Wilder平滑ATR必须另标口径，不能混算。用时间序列滚动回测过的模型给出方向判断；未验证时只能给描述性“偏涨、偏跌、无方向优势或资料不足”，不输出概率。

### 盘中入场候选

2026-10-14初始固定突破规则历史路径试算扣费后为负，尚无已验证的盈利模型。以下数值是研究候选参数，可以形成条件化开仓计划，但不能声称已证明有效。参数在训练期确定并冻结，经独立时间段检验后才标为经验证；不得为当前行情临时调参追求命中。模型未验证不等于AI控盘证据，也不因此单独禁止开仓。

先区分两种候选形态：突破后回踩仍守住已知结构位；已有趋势中回调至结构位后恢复。空头用反向条件，必须先确认平台允许该操作及其履约/转让方式。回踩确认只使用已经完成的 K 线；若要求下一根确认，只能在下一根结束后或更晚尝试入场。

每次计划把“结构位”写成可复核的价格与形成时间：突破候选可用突破前12根已完成5分钟K线的最高/最低价，首次突破后冻结该价；回调候选须说明既有趋势、已确认支撑/阻力及恢复条件。均线周期也须固定，例如EMA21的平滑系数为2/(21+1)。入场前登记回踩容差、确认条件和失效期限，不随之后行情改写。做多可将已完成回踩K线高点加1个最小价位作为再次上破触发，止损置于该回踩结构低点外；做空反向。实际是否触发仍须实时成交确认，触发价不等于成交价，也不保证盈利。

候选入场必须同时满足：

- 方向：价格在已完成周期均值/趋势线一侧；突破候选须突破已冻结前高/前低，回调候选须恢复预先登记的趋势条件；
- 成交确认：价格突破/恢复后没有立即回到失效侧；可研究成交量达到过去20根同类 K 线中位数1.2倍的筛选，但该阈值目前未验证，同一时段季节性须控制；
- 成交可行：买一卖一价差、深度、预计滑点和费用后，目标收益至少为预计风险的1.5倍；
- 盘口确认：实际成交与报价支持可执行性，若需主动买卖方向须先核实标记算法。静态挂单不等于资金流，深度被移走可能由撤单或成交引起，不凭快照断言“撤单”；
- 时段：处于已核实交易时段，距离本品种收市、风险释放和强制处理留有退出时间；
- 资金：使用用户确定的单笔、每日、同时持仓风险预算，按净值与可用资金计算，不能按订金倍数决定数量。预算缺失时只给每批风险和条件，不虚构账户可承担数量。

突破后价格已超出允许成交区间、价差或滑点超过预算、成交量只在单笔异常成交中出现，或预先登记的确认条件未达成时，输出“等待触发”。不要追涨杀跌，不把涨停/跌停价格当作一定可成交价格。

### 离场优先级

入场前同时写出触发价、允许成交区间、失效位、止损、止盈、最晚退出与计划有效期。价格按本品种最小变动取整；结构止损向失效位外侧取整，重算风险，不能为凑仓位把止损移回结构内。允许成交区间按滑点预算确定；报价越界就等待新计划，不把触发价强行当作成交价。1R/2R分批止盈、ATR移动退出、30分钟时间止损只是候选退出方案，分别回测，提前选择，不能事后挑最赚钱路径。R为每批入场到结构止损的价差；成本后的亏损通常大于R，目标净利润通常小于名义目标。

已持仓时读取方向、成本、数量、冻结量、可转让量、已有止盈止损和当前风险率。优先解释“继续持有/减仓/退出”的条件，避免为了实现昨日看涨预测而扩大亏损。离场处理优先于新增信号：

- 硬止损：价格触及结构失效位或预设 ATR 风险位，按下一可成交价估算；发生跳价、封板或无对手盘时记录“无法保证止损价”；
- 止盈：按预先选定方案在结构目标或目标R退出；分批数量按整数批，1批不能拆成半批，剩余批次重新核算费用和风险；
- 移动退出：达到1R后，止损只能向有利方向移动，不能扩大原始风险；
- 时间止损：达到预先登记的最长持有时间、入场理由消失或进入收市退出缓冲期，提出退出；不能等到市场已关闭才计划自主成交；
- 流动性退出：价差、可成交深度或实际滑点超过入场假设，立即减仓/退出；
- 规则退出：公告改变时段、订金、限仓、费用、风险率或交收，重新核算受影响计划与退出条件；已生效暂停交易或禁止新订货时，按公告说明实际执行限制；
- 强制风险：平台风险率达到规则阈值时，不能等待“反弹”，按最坏可成交价格计入损失；
- 交收退出：临近最后交易日、入库申请截止日或交收日，没有交收能力和文件时不得持仓赌方向。

净收益按每批实际计价单位计算：

`净收益 = 方向 × (实际出场价 - 实际入场价) × 批数 - 已确认全部费用`，方向为多头+1、反向-1，须符合平台盈亏定义。

实际成交价已包含买卖价差和滑点，不重复扣费；用中间价/信号价试算才另计价差和滑点。DGKZ普通买卖往返交易费按快照为2元/批，DGJJ为3元/批；交收为独立情景，计货款、税费、交收/仓储等适用费用，不直接当作普通平仓。

将止损移到入场价不等于净保本。每批净保本退出价满足方向×(退出执行价-入场执行价)≥全部往返费用；还需留出退出滑点并按最小价位取整。可成交的保本位尚未到达时，不标“已锁定不亏”；价格跳变或无对手盘时也不能保证该价成交。

每批止损压力损失 `L = 方向×(入场执行价-压力退出价)+全部交易费`；目标净收益 `G = 方向×(目标执行价-入场执行价)-全部交易费`。要求L>0、G>0，候选净盈亏比G/L至少1.5只是筛选，不证明正期望。经校准的胜率p存在时才计算 `p×G-(1-p)×L`；否则不填期望收益数字。

数量取以下上界的最小整数：单笔预算/L、剩余每日损失预算/L、可用资金约束、账户风险率约束、可成交深度和平台数量限制。不足1批则观望。DGKZ/DGJJ同时持仓共享总风险预算，不能假定相关性为0。达到每日损失上限或最大连续亏损限制，停止新增交易，禁止摊平、翻倍补亏、亏损时放宽止损。

若风险率确按上述F10定义，压力检查为(当前权益-已有仓位从当前时点起的额外压力损失-q×L)/(现有持有订金+q×新增每批订金)，q为新增批数。已计入当前权益的亏损不重复扣除；冻结订金、浮盈、费用及可用资金口径以实际规则为准。压力风险率须高于20%并留用户选定缓冲，接近阈值不能用“尚未触发”代替可承受风险。

## “AI控盘”与自动化行为审计

“AI控盘”包含两个独立问题：是否有自动化交易；是否存在足以改变市场成交的异常行为。识别到机器人也不能确定使用AI，更不能确定操纵意图、幕后主体或违法事实。区分正常程序化报价/做市、数据加工/模拟、订单行为异常和监管认定，不能把它们排成必然升级关系。

2026-10-14初始原始1分钟样本（均剔除10月14日自然日）：DGKZ的5842根中5056根振幅恰为3个最小价位，约86.55%；DGJJ的5842根中5425根也是3个价位，约92.86%。这是描述性规律，不是AI概率。两个样本时间窗不同，全部源于平台同一行情服务，没有订单级独立验证；报价机制、聚合/生成方式或交易结构均可能解释。对重复形态先核实原始逐笔能否聚合得到对应OHLC，不直接据此创建获利策略。

在授权和行情使用范围内，保存去除账户信息的逐笔成交（时间、价格、数量及经核实方向）、六档盘口序列、订单事件（若提供）、规则版本、公告和网络延迟。不要为检查跨客户端一致性创建或使用未授权账户。优先检验：

1. 报价是否长期在固定价位重复出现、成交后是否规律补回；
2. 大单出现前后价格、深度和成交量是否有可重复的统计变化；
3. 有订单ID/逐条事件时才计算撤单率和存活时间；只有盘口快照时计算显示深度变化，承认无法区分成交、撤单、改价和隐藏订单；
4. 价格是否在没有成交支持时跳变，或不同客户端/时间戳看到的行情是否不一致；
5. 规则、费用、收市风险释放和人工处理是否足以解释该行为。

用同品种、同会话、相似波动与价差的历史基准，时序检验保留自相关（例如分块重采样），报告效应、样本区间、遗漏事件与多重检验。不得将普通随机打乱时间造成的差异称为异常证据。

结论标签：无可用证据 / 观察到规律 / 可重复数据或订单异常待核查 / 已有独立调查结论。没有订单或模型架构证据不写AI控制概率，不指认主体。

用户要求：没有AI控盘证据时允许正常评估开仓。前两种标签均不触发暂停，不给风险分数任意加权，不因“怀疑AI”降低仓位或否决满足条件的计划。可重复异常也须注明证据与具体执行影响，不能自动判为控盘。只有实际盘口缺失、价格相互矛盾、平台拒绝接单或已生效停牌等直接影响成交的事实，才说明无法据当前数据计算/执行；这属于成交事实，不是AI猜测。重算成本、压力损失和退出可行性。核查或监管咨询只提出建议，未经授权不发送材料。

## 回测与记录

按时间切分训练、参数选择、样本外验证，跨分界的持仓应隔离；参数优化次数计入评估。禁止随机打乱、未来数据泄漏、用确认K线完成前价格入场。同根K线同时触及止损/止盈而无逐笔顺序时，采用止损先到或报告上下界；未成交限价、跳空和封板不能伪造理想成交。纳入相应历史费用、风险释放、会话截止和实际可成交时间。

方向预测比较历史多数方向和前日延续基准；净收益比较空仓、固定低复杂度规则和完整费用情景。报告覆盖率、样本数、独立交易日数、各方向命中、净收益、最大回撤、连续亏损、利润因子、无法成交比例；用按交易日分块的区间反映相关性。30笔不是可靠性保证；样本少、同日重复信号多、规则期短或费用压力情景亏损时，均保留“研究候选”。

每次预测记录：代码、期次、发布时间、数据截止、有效时段、方向条件、触发价、止损、止盈、最晚退出、费用假设、反证、实际成交和退出、净收益、失败原因。盘中修改保留版本。没有实际成交价时，只能做理论路径回测，不写成已实现盈利。

## 结果格式

每个品种分别给出：

1. 数据状态、当前北京时间、交易日/会话、行情截止和来源；
2. 行动状态：持仓维持/减仓/退出条件，或条件满足可开仓（研究计划，由用户执行）/等待触发/资料不足；方向状态另列偏涨/偏跌/无优势。无AI证据不暂停开仓；
3. 条件计划：形态、触发价、允许成交区间、失效位、目标、时间止损、最晚退出及有效期；
4. 净收益G、压力损失L、成本与滑点假设、预算允许批数（预算不明则不填）、规则风险率压力；
5. 相反证据、AI/自动化证据标签、模型验证状态。

价格必须来自本次有效数据，静态历史快照不能在未来作为当前入场价。未取得实时行情时只输出条件化计划，不给“立即买入/卖出”。技能运行成功或格式验证通过不代表策略有效。
