# 唯一当前交易流程

读取浏览器真实行情交给AI。普通入场必须由AI明确BUY买多或SELL买空，短线趋势和当前相对位置支持交易就入场。方向盈利概率仅作参考，不设概率门槛，缺失概率不能否决BUY/SELL；程序不按较高概率猜方向。HOLD或模型失败不新开仓。手续费无需配置，费用未知、利润估算、计划格式及可选保护字段不合理不能阻碍AI入场。手动模式填表由用户提交，自动模式执行AI决定。单笔数量使用用户配置。

只有真实持仓、持仓汇总和当前委托均核实清零，才能开始新一轮入场。入场后只管理本轮持仓，不追加普通单、不反向救单。持仓及当前委托全部核实清零才结束本轮，不把点击或提示成功当成交。

## 入场与未来预测

主动、大胆预测最可能的主场景，预测当前周期下一根及随后1～3根K。analysis_summary开头写“主判断：偏涨/偏跌/震荡”，forecast_horizon.next_k和forecast_horizon.next_3k提供预计路径、概率、在哪根未来K入场与盈利离场及失效位。max_hold_sec与预测期限一致。即使HOLD也给出预测路径和具体价格依据。只有当前确实无短线方向或数据无法判断才HOLD，说明缺少什么及下一次触发点，不能因普通指标分歧、旧概率门槛或精确锚点要求持续观望。用诚实概率与反证表达，不人为抬高概率，不保证盈利。

按短线趋势在相对低位买涨、相对高位买跌，有机会即决定，不等绝对最低或最高，也不强求支撑反弹、阻力受阻或指标共振。禁止随机入场。尽量提供trade_plan，作为原始预测和风险管理依据：

- setup：AI对短线入场依据的描述，不限固定形态。
- entry_zone.min/max：参考入场区间，可为null；anchor_price和anchor_timestamp可选，只能引用真实已确认K线，不能编造。缺失、越界或无法精确匹配均不阻止入场。
- take_profit_price、stop_loss_price、hard_stop_price：未来盈利目标、假设失效价与不可放宽的最大风险价。
- stop_confirmation_sec：0～300整数，由当前波动和结构决定普通止损连续确认秒数；不能使用无限等待。
- valid_for_sec：1～3600整数，复核期限；max_hold_sec：1～86400整数，最长持仓时长。
- profit_protection可选：提供时给出activation_price、floor_price和trailing_distance；无效则不启用该附加保护，继续执行核心目标和止损，不伪造价位。
- rationale、invalidation：价格依据、短暂噪声与结构失效的区分。

闪K或PROVISIONAL未定价期间禁止下单，保留AI明确的BUY/SELL方向，真实定K后再触发；每分钟第50秒后连续稳定超过5秒才确认，闪K事件计时到期或复读缓存不能冒充真实定价。正常已定价时不额外等下一根K。MARKET使用真实买入ask或卖出bid，提交与确认前刷新实际价格；LIMIT保留AI明确target_price或entry_price。概率、固定形态、锚点、参考区间及trade_plan缺失或不完整均不能把明确BUY/SELL改成HOLD；不能从watch_conditions自动生成订单，不将HOLD改成随机方向。

入场后一出现持仓，优先绑定原入场预测，即使实际成交略超参考区间也保留有效目标和止损；最长持仓期限从实际入场起算。无有效计划立即独立请求并明确提示，不伪造默认止损。停止开关、正确品种与数量、未知提交先对账继续有效，不恢复账户或格式二次否决。

不要求strategy.tradingCosts，不推测费用为0，不把价差当作已实现净收益或金额。

## AI汇总离场计划

持仓一出现即独立请求结构化AI计划，无需等到亏损。保留原始入场预测、当前持仓、有效计划、盘口及离场后3/5分钟观测作为上下文。HOLD也必须返回完整plan；EXIT另给exit_price，表示多单当前可接受最低转让价或空单最高回补价。

独立监控全部N笔持仓，读取“持仓汇总”的商品、方向、真实订立均价、数量与冻结量。多单点差=整行最差可成交bid-均价；空单点差=均价-整行最差可成交ask。单行点差不是金额；合计时乘各自真实数量，不能遗漏负值、把未知报价当0或只看买一一手价格。

正常持仓跟随原始AI目标与预计离场K。例如16～19入场、目标21，预测未明显失效就持有至21；不因浮盈转正、只持有一根K或60秒复核到期退出。复核保留原始目标和原最长持仓期限，不能随意提前目标或压缩期限。

对冲规则仅用于同时持有多空：合计可成交价差乘数量>0锁定全部离场，锁定后不因先退部分变负而停止；合计未盈利先退亏损侧，保留盈利侧。亏损侧持仓与委托确认清除后，盈利侧最多观察60秒，回落或转非正提前离场，持续增加到时也兑现，不延长期限；先到AI目标也兑现。硬风险边界持续有效，该规则无须AI计划返回即可执行。

离场由确定性算法先检查定价状态。闪K或PROVISIONAL期间所有离场均等待，包括目标、普通止损、硬止损、利润保护、最长持仓及多空规则，AI不能绕过。保留等待状态，事件计时结束、缓存复读或图表缺失不能解除；真实定K后按最新可成交报价重新判断，恢复则不离场。闪K期间持续记录新鲜真实可成交报价的连续止损风险，不因新K重置；报价恢复或采样中断则重新观察，缓存不增加确认时间，闪K不抬高保护峰值。定K后到达AI目标立即整行离场，不额外等预测K；普通止损已按真实报价连续突破AI指定秒数，定K仍越界就执行，硬止损命中则直接执行，不再请求AI许可。原目标前主动EXIT仍须forecast_invalidated=true及invalidation_candle_timestamp，引用入场后已确认1m历史K并说明预测偏差。

新AI计划可收紧止损与有效保护，保留原目标及原最长持仓期限；计划复核到期仍保留已有边界并继续请求更新，复核到期不等于离场到期。无法保证避免所有止损后3～5分钟反弹，必须记录并复核，不用事后价格冒充事前预测。

程序点击持仓汇总对应商品方向整行“转让”，一次提交整行数量，不降级逐仓操作。两种入场模式均自动执行用户规则和有效AI风险计划；点击和最终确认前重核均价、数量、冻结量、新鲜报价、深度与授权。单笔失败继续处理其他持仓。

实际提交价与计划报价分开保存。提交结果未知先核实，不能盲目重复。超过120秒，只有两次不同时间的新鲜账户快照确认无相关委托、冻结解除且剩余同向持仓一致，才允许按剩余数量重新执行计划；不伪造历史成交结果。当前委托满120秒仅撤未成交余量，核实撤单和剩余持仓，不查询历史委托。

## 指标和有效K线

MACD：DIFF=EMA(CLOSE,SHORT)-EMA(CLOSE,LONG)，DEA=EMA(DIFF,M)，MACD=2*(DIFF-DEA)。KDJ：RSV=(CLOSE-LLV(LOW,N))/(HHV(HIGH,N)-LLV(LOW,N))*100，K=SMA(RSV,M1,1)，D=SMA(K,M2,1)，J=3*K-2*D。参数必须来自实际数据，缺失不冒充默认；递推SMA不能当简单平均，HHV=LLV时不可计算RSV。

MACD与KDJ同时交叉、89均线、快线、前高前低及动能峰值对应影线可作辅助证据，不能脱离价格响应、多周期结构、成交量、盘口和执行可行性直接下单。静态挂单不代表已成交量，不能仅按厚单机械判断反转。

每分钟第50秒之后连续稳定超过5秒才确认新K。未定 K 和闪 K 的瞬时 OHLC 以未确认盘中证据交给 AI，不能一律判假、删除或忽略；不进入已确认历史指标、不作支撑阻力锚点、不触发离场。原目标和止损价不变，定K后重新核对执行；不能用闪K推断操盘者身份。

确认历史须递增、OHLC有效，无未来、重复或跨品种残留。停止任务取消未完成请求，丢弃迟到结果。禁止编造行情、费用、成交、凭证或保证盈利。
